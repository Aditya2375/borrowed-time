# Phone test checklist

Do this on a real Android phone. You need two people and two phones for the group steps. Write what happened in the last column. "Pass" means it did what the step says.

Install: open the latest `borrowed-time.apk` from the Releases page, allow installs from your browser if asked.

| # | What to do | What should happen | Pass? / notes |
|---|---|---|---|
| 1 | Open the app, tap Start a group, pick a name and a group name. | You get a group code on the home screen. | |
| 2 | On the second phone, tap Join with a code and enter it. | Both phones show each other in "The group". | |
| 3 | Go through the switches screen. Allow usage access and display over other apps. | Each row turns green. Continue unlocks. | |
| 4 | Pick Instagram and YouTube (or two apps you use) and a 5 minute limit. | The app opens its home screen with about 5 minutes left. | |
| 5 | Open one picked app for a few minutes. Open Digital Wellbeing next to it. | Borrowed Time's "used" is within about a minute of Digital Wellbeing for those apps. | |
| 6 | Keep using the app until time is up. | A "You've spent today's time" screen covers the app. | |
| 7 | With time up, try to get back in: through the launcher icon, from recents, and from a notification. | The pause screen shows each time. | |
| 8 | Restart the phone. Open a picked app. | The pause screen still shows (the guard restarts by itself). | |
| 9 | Force-stop Borrowed Time in Settings, then open a picked app. | Note whether it is blocked. On the other phone, wait about 10 minutes: it should show "Guard silent". | |
| 10 | Tap Ask your friends, pick 10 minutes, write a note. Send. | The other phone gets a notification with Give and Not now. | |
| 11 | Put the other phone's screen to sleep for a few minutes first, then send an ask. | Note how long the notification takes to show up. | |
| 12 | Give the time from the other phone. | The pause screen clears on the first phone within a minute. Time left matches. | |
| 13 | Use up the extra time. | The pause screen comes back. | |
| 14 | Ask three times in one day. Try a fourth. | The fourth is refused: "no asks left today". | |
| 15 | Try to approve your own ask (if you can find a way). | It is refused. | |
| 16 | On the first phone: Settings, Leave group. Then rejoin with the same name. | The other phone shows "Left the group". Rejoining is refused for a while. | |
| 17 | Change the phone's date forward a day (Settings, Date). Wait a minute. | The home screen shows a clock warning. Time left does not reset. | |
| 18 | Change the phone's timezone. Wait a minute. | Time left does not reset. | |
| 19 | Turn on airplane mode. Use a picked app until time is up. | It still blocks. The home screen shows Offline. | |
| 20 | Enter a wrong group code on the join screen. | A clear "doesn't match a group" message. | |
| 21 | Install a newer version over this one (when there is one). | It installs without removing the old one. Your group and apps are still there. | |
| 22 | Leave the phone for 24 hours with the screen on and off. | Next day: the guard is still running (check "last seen" on the other phone). Note the battery use. | |
| 23 | Uninstall the app while the pause screen is showing. | Note what happens. The other phone should show "Guard silent" or "Left the group". | |
